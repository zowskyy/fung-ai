# 2D Character Animator (Godot 4 addon)

A character-animation plugin for Godot 4.x (targeted at 4.4) covering three
animation approaches in one tool:

1. **Sprite-frame clips** — author `AnimationClip` frame regions straight off a
   sprite sheet and play them with a lightweight `CharacterAnimator`.
2. **AnimationTree state machine** — a generator converts your clips into an
   `AnimationPlayer` + root `AnimationNodeStateMachine` (idle/walk/run/jump/
   fall/land/crouch) driven at runtime by `CharacterAnimationDriver`.
3. **Skeletal (bone) animation** — `CharacterRig`/`CharacterSkeleton`
   (Skeleton2D/Bone2D) plus `BoneClip`/`SkeletonAnimator` for procedural bone
   animation.

## Install

Copy the `addons/character_animator` folder into your project and enable it in
**Project > Plugins**. The plugin registers custom resource types
(`CharacterAnimationProfile`, `AnimationClip`, `CharacterRig`, `BoneClip`, ...)
and adds a dock (**2D Character Animator**) with Clips, Rig and Setup tabs.

## Quick start

Open the `godot_project` folder in this repository in Godot 4.4 to run the demo
scene, or replicate it in your own project:

```gdscript
# 1. Place a CharacterAnimator (Sprite2D) with clips authored in the dock.
# 2. Create a CharacterAnimationProfile pointing at it:
var profile := CharacterAnimationProfile.new()
profile.animator_path = target.get_path_to(animator)
profile.idle = &"idle"
profile.walk = &"walk"
profile.run = &"run"
profile.jump = &"jump"
profile.fall = &"fall"
profile.land = &"land"

# 3. Generate the AnimationTree graph:
var result := AnimationGraphBuilder.build(target, profile)

# 4. Drive it from your controller:
driver.profile = profile
driver.animation_tree = result["animation_tree"]
driver.visuals = visuals_node
driver.update_locomotion(velocity, is_on_floor(), is_crouching(), facing_right)
```

## Testing

From the `godot_project` directory:

```
godot --headless --path . --import
godot --headless --path . --script res://tests/run_tests.gd
```

The suite asserts clip playback, the generated state machine transitions,
skeletal pose sampling, the validator, event receiving and the scene scanner.
CI runs the same commands on Godot 4.4.1.

## Design notes

- The plugin is a system **builder/driver**: it generates and drives Godot's
  own `AnimationTree`; it never owns physics or renders its own state machine.
- Every node/animation generated by `AnimationGraphBuilder` is tagged
  `character_animator_generated`; regeneration only replaces generated content.
- Editor mutations go through `UndoService` so dock edits are single undo steps.
